# Lexique : les mots du closing

Tous les mots techniques du livre, rangés par ordre alphabétique. Pour chaque mot : ce qu'il veut dire **en simple**, et sa **traduction en anglais** (utile pour les vidéos et les livres étrangers).

| Mot | Sens simple | Anglais |
|---|---|---|
| **Abus de faiblesse** | Profiter d'une personne fragile pour lui vendre. | Exploitation of vulnerability |
| **Accueil** | La façon dont tu reçois le client dans les premières secondes. | Greeting / welcome |
| **Acompte** | Une partie du prix payée d'avance pour réserver. | Deposit / down payment |
| **Annulation** | Quand le client dit « non » après avoir dit « oui ». | Cancellation |
| **Argument** | Une raison que tu donnes pour convaincre. | Argument / selling point |
| **Auto-évaluation** | Te donner une note toi-même, honnêtement. | Self-assessment |
| **Bénéfice client** | Ce que le client gagne vraiment avec ton produit. | Customer benefit |
| **Biais de cohérence** | On veut rester d'accord avec ce qu'on a déjà dit. | Consistency bias |
| **Boîte à histoires** | Ta liste d'histoires vraies, une pour chaque peur fréquente. | Story bank |
| **Bonus** (ou petit plus, cadeau, *jara*) | Un petit cadeau à la place d'une baisse de prix. | Bonus / add-on |
| **Boucle** | Ramener gentiment le client dans la discussion quand il veut partir. | Looping |
| **Bouche-à-oreille** | Quand les clients parlent de toi à leurs proches. | Word of mouth |
| **Catalogue WhatsApp** | La vitrine de tes produits dans WhatsApp Business. | WhatsApp catalog |
| **Client fidèle** | Un client qui revient acheter chez toi. | Loyal / repeat customer |
| **Closer** | Le vendeur qui sait amener un client qui hésite jusqu'au « oui ». | Closer |
| **Closing** | Le moment où le client dit « oui » et paie, et tout ce que tu fais pour l'y amener. | Closing |
| **Commande fantôme** | Une commande passée par quelqu'un qui n'a jamais eu l'intention de payer. | Fake order / ghost order |
| **Confirmation de commande** | Le message qui vérifie que le client est vraiment d'accord avant l'envoi. | Order confirmation |
| **Conversion** (taux de) | Sur 10 personnes qui demandent, combien achètent. | Conversion rate |
| **Crédit** (vente à crédit) | Le client prend le produit et paie plus tard. | Store credit / selling on credit |
| **Décideur** | La personne qui a le dernier mot sur l'achat. | Decision-maker |
| **Démasquer** | Faire tomber le rideau pour découvrir la vraie raison. | Uncover / clarify |
| **Détail concret** | Un petit fait précis qui rend une histoire crédible. | Concrete detail |
| **Devis** | Le document qui dit combien coûtera ce que le client veut. | Quote / quotation |
| **Écoute active** | Écouter vraiment, et montrer qu'on a compris. | Active listening |
| **Engagement** (frais d'engagement) | Une petite somme payée pour montrer qu'on est sérieux. | Commitment fee |
| **Étiquetage** | Nommer ce que la personne semble ressentir (« On dirait que… »). | Labeling |
| **Fausse urgence** | Faire croire qu'il faut acheter tout de suite alors que c'est faux. | False urgency |
| **Fenêtre** (des premières secondes) | Les quelques secondes où le client décide de rester ou de partir. | Engagement window |
| **Frais cachés** | Un coût qu'on découvre seulement au moment de payer. | Hidden fees / drip pricing |
| **Habitude** | Ce que tu fais sans y penser, parce que tu l'as fait souvent. | Habit |
| **Histoire** (storytelling) | Raconter ce qui est arrivé à un vrai client pour faire comprendre. | Storytelling |
| **Inbox** (« prix en inbox ») | Le message privé. « Prix en inbox » = prix caché, donné seulement en privé. | Inbox / DM |
| **Interroger** | Poser des questions pour comprendre le besoin du client. | Discovery / questioning |
| **Jeu de rôle** | Faire semblant d'être le client et le vendeur pour s'entraîner. | Role play |
| **Journal des objections** | Le cahier où tu notes chaque client qui hésite, et pourquoi. | Objection log |
| **Livraison** | Le moment où le produit arrive chez le client. | Delivery |
| **Livreur** | La personne qui apporte le colis et souvent encaisse l'argent. | Delivery rider / courier |
| **Manipuler** | Pousser quelqu'un à agir contre son intérêt, par le mensonge ou la pression. | Manipulate |
| **Marchandage** | Discuter le prix, comme un jeu social. | Haggling / bargaining |
| **Message vocal** | Un message enregistré avec ta voix. | Voice note |
| **Mobile money** | L'argent sur le téléphone (Orange Money, Wave, M-Pesa…). | Mobile money |
| **Mur** (objection-mur) | Un vrai problème qui empêche d'acheter maintenant. | Genuine objection |
| **Négociation** | Discuter pour arriver à un accord sur le prix ou les conditions. | Negotiation |
| **Objection** | La raison que le client donne pour ne pas acheter maintenant. | Objection |
| **Paiement à la livraison** | On paie quand on reçoit le produit, pas avant. | Cash on delivery |
| **Paiement en plusieurs fois** | Payer le prix en 2 ou 3 parties, à des dates fixées. | Installment payment |
| **Persuader** | Aider quelqu'un à décider avec des vérités et des preuves. | Persuade |
| **Politique d'échange** | Tes règles écrites pour échanger ou rembourser un produit. | Return policy |
| **Porte** | Une autre solution quand il y a un vrai problème (un mur). | Alternative / workaround |
| **Pratique agressive** | Mettre trop de pression sur le client. | Aggressive practice |
| **Pratique trompeuse** | Faire croire quelque chose de faux pour vendre. | Misleading practice |
| **Preuve de confiance** | Tout ce qui montre au client que tu es sérieux (vidéo, adresse, avis…). | Trust signals |
| **Preuve sociale** | Le fait que d'autres personnes ont acheté et sont contentes. | Social proof |
| **Prix « tout nu »** | Un chiffre donné seul, sans rien autour. | Bare price |
| **Prospect** | Quelqu'un qui pourrait acheter, mais n'a pas encore acheté. | Prospect / lead |
| **Publicité mensongère** | Une annonce qui dit des choses fausses. | False advertising |
| **Qualifier** | Vérifier que le produit est vraiment bon pour ce client. | Qualify |
| **Question de la dernière chance** | La question courte qu'on pose quand le client commence à partir. | Last-chance question |
| **Racoleur** | Un vendeur qui retient ou attrape les clients. | Tout / pushy seller |
| **Réassurance** | Ce qui fait disparaître la peur du client. | Reassurance |
| **Reformulation** | Redire avec tes mots (ou ses mots) ce que le client a dit. | Rephrasing / paraphrasing |
| **Relance** | Recontacter un client qui n'a pas encore décidé. | Follow-up |
| **Réputation** | Ce que les gens disent de toi quand tu n'es pas là. | Reputation |
| **Réservation** | Mettre un produit de côté pour un client, souvent avec un acompte. | Reservation / hold |
| **RIDEAU** (méthode) | Les 6 clés de ce livre : Retenir, Interroger, Démasquer, Écouter, Apaiser, Unir. | RIDEAU method |
| **Rideau** (objection-rideau) | Une excuse qui cache une autre raison. | Smokescreen objection |
| **Service après-vente** | Ce que fait le vendeur pour le client après l'achat. | After-sales service |
| **Système pyramidal** | Une fausse affaire où l'on gagne seulement en faisant payer d'autres personnes. | Pyramid / Ponzi scheme |
| **Témoignage client** | Ce qu'un vrai client raconte de son expérience. | Testimonial |
| **Tontine** | Un groupe où chacun cotise et reçoit à son tour une grosse somme. | Rotating savings group (ROSCA) |
| **Unir** | Conclure ensemble, par un petit pas, puis garder le client. | Close and retain |
| **Valeur perçue** | Ce que le client **pense** gagner en achetant. | Perceived value |
| **Vraie raison** | Ce que le client pense vraiment, derrière ses mots. | Real objection |
